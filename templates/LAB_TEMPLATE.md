# Lab NN - Descriptive Title

## Objective

State the physical or numerical question and the expected behavior.

## Model and nuclear data

Specify materials, geometry, boundary conditions, temperatures, nuclear-data
library and processing, software versions, and data checksums where available.

## Experiment design

Identify the changed factors and quantities held fixed. Tabulate source
definitions, particles, batches, inactive batches, generations per batch,
threads, and random seeds. State which comparisons are independent.

## Reproduction

Link runnable code and exact inputs. Provide prerequisites and commands for
transport calculations and for regenerating tables and figures from stored data.

## Results

Include machine-readable data and labeled figures. Specify units, normalization,
uncertainty definitions, and run identifiers. Report all runs used in the analysis,
including unexpected results.

## Analysis

Explain the physical and statistical interpretation of the results. Distinguish
observations from inferences and compare with the initial expectation.

## Limitations

State unresolved uncertainties, untested assumptions, and systematic effects
outside the reported statistical uncertainty. Describe any verification checks
and distinguish them from validation against experimental measurements.

## Conclusion

Answer the experimental question within the limits of the available evidence.

## References

Link the primary sources supporting the model, methods, and interpretation.
