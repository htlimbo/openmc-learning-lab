# Public Archive Scope

The experiment archive contains scientific inputs, results, code, and analysis.

Included for scientific reproduction:

- OpenMC version and dependency requirements.
- Model dimensions, material compositions, temperature, boundary conditions,
  nuclear-data identifiers and checksums.
- Particle counts, seeds, batches, generations per batch and simulation threads.
- Sanitized statepoint snapshots, input XML, numerical tables and figures.
